# Linear Regression with PyTorch — Tutorial

A notebook-based tutorial on implementing a linear regression workflow with PyTorch.

## Notebook
- `Linear_Regression_With_Pytorch_in_hidi_urdu__episode_2_.ipynb`

## Topics
- Preparing inputs and targets
- Building a linear prediction function
- Calculating regression loss
- Training with autograd and an optimizer
- Reviewing model predictions

## Run
Open the notebook in Jupyter or Google Colab and install the imported dependencies.

## Scope
Educational tutorial. Refer to the notebook for the dataset, model details and exact training configuration.
